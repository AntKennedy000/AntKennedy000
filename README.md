# Dados aplicados a Crédito e Risco

Profissional do setor bancário, com atuação na linha de frente em diferentes jornadas de produtos financeiros para pessoas físicas, incluindo concessão de limites, cartões, crédito pessoal e consignado, renegociações e etc. Bacharel em Engenharia Civil, com pós-graduação em Engenharia de Software e Data Science, graduação em Engenharia da Computação em andamento e certificações profissionais do mercado financeiro, venho direcionando essa vivência de negócio e base técnica para crédito, risco e dados. Neste portfólio, desenvolvo projetos educacionais com dados públicos ou fictícios sobre políticas de crédito, fraude, análise de dados e engenharia de dados, buscando transformar informações em decisões mais explicáveis e responsáveis.

## Projetos selecionados

| Projeto | Aplicação |
|---|---|
| [Motor de Políticas de Crédito](https://github.com/AntKennedy000/credipolicy-motor-de-credito) | Simulação educacional de políticas de crédito, limites, decisões explicáveis e precificação ilustrativa. |
| [Detecção de Fraudes em Transações](https://github.com/AntKennedy000/deteccao-fraudes-transacoes) | Comparação de modelos para dados desbalanceados com Python, XGBoost, SHAP e métricas de negócio. |
| [Azure Data Factory e Azure DevOps](https://github.com/AntKennedy000/azure-data-factory-devops-versionamento) | Versionamento de pipelines, pull requests e publicação de templates ARM para rastreabilidade de dados. |
| [Clara - Assistente de Crédito Consciente](https://github.com/AntKennedy000/clara-assistente-credito-consciente) | Assistente educacional com IA generativa para esclarecer dúvidas e comparar propostas fictícias de empréstimo. |

## Competências em desenvolvimento

- Análise de crédito, risco e performance de carteira;
- SQL, Python, Power BI, PySpark e Databricks;
- Engenharia de dados com Azure Data Factory, ADLS Gen2 e Azure DevOps;
- Modelagem, validação e explicabilidade de modelos de risco.

## Princípios

Projetos desenvolvidos com dados públicos ou fictícios, documentação de metodologia, resultados, limitações e uso responsável de dados e inteligência artificial.
